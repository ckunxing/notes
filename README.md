# 我的笔记本

- 在线阅读（手机/电脑）：https://ckunxing.github.io/notes/
- 写笔记：用 Obsidian 打开仓库 `notes/` 文件夹（启动 Obsidian 会直接进入）
  - 分组 = 文件夹，左侧直接新建/拖动
  - 图片直接 Ctrl+V 粘贴，自动存到 `images/`
  - 自动排版：Linter / Pangu 插件
- 同步：双击 `同步到GitHub.vbs`（或桌面的「同步笔记到GitHub」快捷方式），
  弹出小窗显示进度，成功后自动关闭，约 1 分钟后手机可见
- 备用：网页编辑器 http://127.0.0.1:8899 （开机自启）
