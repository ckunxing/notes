# 我的笔记本

- 在线阅读（手机/电脑）：https://ckunxing.github.io/notes/
- 写笔记：用 Obsidian 打开仓库 `notes/` 文件夹（已配置好，启动 Obsidian 会直接进入）
  - 分组 = 文件夹，左侧直接新建/拖动
  - 图片直接 Ctrl+V 粘贴，自动存到 `images/`
  - 自动排版：Linter / Pangu 插件（设置里可配规则）
- 同步：双击 `同步到GitHub.bat`，约 1 分钟后手机可见
- 备用：双击 `启动编辑后台.bat` 打开网页编辑器（http://127.0.0.1:8899，开机自启）
